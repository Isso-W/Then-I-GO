# 待讨论清单 & 内容展示策略

**日期**: 2026-05-31
**用途**: 记录还没拍板的设计问题，重点是"给用户展示多少"的取舍，方便团队讨论。每条给出：现状 / 待定问题 / 倾向。

---

## 一、内容展示策略：给用户「看多少」（核心）

这是这次会话反复聊到的主题——哪些信息直接给、哪些藏起来留神秘感、什么时候揭晓。

### 1. 默认强度档（最该先定）
- **现状**：偏好第 5 项默认 / 推荐是「别让我思考」——**无岔路、无神秘**。直接点生成，二叉树和惊喜模式都看不到。
- **待定**：默认要不要改成「正常探索」（默认就有 A/B 岔路），让招牌功能默认可见？
- **倾向**：默认改「正常探索」，惊喜模式留作主动选。否则 demo 不手动改档就平平无奇。

### 2. 惊喜模式里"藏"到什么程度
- **现状**：藏的是**目的地名字**（显示 `？？？`，走到打卡半径才揭晓）；emoji、故事预告、距离都还给。
- **待定**：
  - emoji 要不要也藏？（现在 ☕ 会暗示是咖啡馆，部分剧透）
  - 将来若在卡片上展示评分/人均/人气，这些在到达前是否一起藏？
- **倾向**：emoji 保留（增加好奇但不点破）；评分/价格这类"决策信息"若展示，惊喜模式下也藏，只留"气质"。

### 3. 揭晓时机 & 接近半径
- **现状**：走到目标 30m 内 → 卡头「✓ 到了 · 可打卡」+ 揭晓名字。
- **待定**：30m 是否太严？点 marker 吸附到最近路后可能差几十米，不容易踩中。
- **倾向**：放宽到 50m 更顺手（一个常量，改一行）。

### 4. 二叉树 A/B 露多少
- **现状**：两张卡给 emoji + 名字 + 故事 + 距离；惊喜模式下名字→`？？？`。
- **待定**：非惊喜模式是否也只给"气质"不给名字，让二选一更像"选一种心情"而非"选一个已知地点"？
- **倾向**：保持现状（正常档给名字、惊喜档藏），用档位区分，不一刀切。

### 5. 隐藏任务的"勾人"程度
- **现状**：`HiddenTaskAlert` 给名字（惊喜模式→`？？？`）+ 一句神秘描述 + "立刻前往"。
- **待定**：要不要更克制——只给方位/距离/一句氛围，连非惊喜模式也不直接报名字，强化"秘密坐标"感？
- **倾向**：可做成"非惊喜也半遮"，但优先级低，先观望。

### 6. 故事页 / 统计数字（基本已定，列出供确认）
- **故事页（StoryScreen）**：行程结束后展示**真名**——回顾就该揭晓。（已定）
- **MineScreen 统计**（28天/86km/56任务…）：**刻意保留的"有人气"假数据**——demo 卖愿景，做成真实会显空账号。（已定）若转真实产品，需要 localStorage「行程历史」层把它们做真。

## 三、已定决策（记录在案，避免反复讨论）

- **地点**：上海/柏林 → 北京五道口（脏数据已清）。
- **POI 落位**：全部落在**路上**（公园/校园不再放多边形内部，否则导航能导但人走不过去）；terrain 多边形仅做地图底色。
- **后端**：14 天后端重写计划已删——不做独立后端，直接演进 React 原型。
- **接近打卡**：是"**提醒**"不是"门控"——路上看到猫/花随时能记录，到达只是提示可打卡。
- **铃铛 vs 系统消息**：拆成两个面板（铃铛=动态通知，系统消息=常驻公告），内容从当前 session 合成。
